# LANZA LA MONEDA

Experiencia web interactiva y minimalista para lanzar una moneda 3D. El resultado (Cara / Sello) se determina antes de la animación y la moneda siempre aterriza mostrando exactamente ese resultado. Incluye selección de diseños de moneda, modo retos, historial y persistencia local.

## Stack

- React + TypeScript + Vite
- Three.js / React Three Fiber / drei
- Tailwind CSS
- Framer Motion
